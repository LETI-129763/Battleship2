## Overview

This quality gate uses Qodana and GitHub Actions to detect the **Long Method** code smell, which occurs when a method is too long. This can reduce readability, testability and maintainability.

## Mapping Table (Fowler smell → Qodana inspection)

| Cheiro (Fowler) | Inspeção no IDE | ID da inspeção | Métrica / limiar | Limitações |
|---|---|---|---|---|
| Long Method | Overly long method | `OverlyLongMethod` | LOC; limiar por omissão: 30 (VERIFICAR); limiar usado: 20 (`m_limit`) | Só mede o tamanho do método, não a complexidade ciclomática. O limiar é absoluto, e não relativo ao sistema como no livro (Tabela 2: LOC/Método 7, 10, 13 e 19,5). |

## Inspection Configuration

| Property | Value |
|---|---|
| Code smell | Long Method |
| Inspection | Overly long method |
| Inspection ID | `OverlyLongMethod` |
| Metric | Method length (LOC) |
| Threshold | Maximum 20 (`m_limit: 20`) |
| Severity | WARNING |
| Violation | Methods longer than 20 |
| Quality concern | Readability, testability and maintainability |

The configuration is defined in:

- `qodana-129763.yaml`
- `.qodana/profiles/profile-129763.yaml`
- `.github/workflows/qodana-smell-129763.yaml`

The inspection profile enables only `OverlyLongMethod`, starting from an empty base profile. The quality gate is configured to fail when the number of reported problems exceeds the permitted threshold (`severityThresholds.any`).

## Reflection

Qodana successfully detected the Long Method code smell using method length and cyclomatic complexity metrics, demonstrating how static analysis can identify potential maintainability issues.
False positives may occur when long or complex methods are justified, while false negatives may arise when poorly designed methods remain below the configured thresholds.
Lowering these thresholds increases detection sensitivity but may also produce more false positives.
Unlike more comprehensive detection strategies that combine multiple metrics and system-relative thresholds, our quality gate evaluates each inspection independently;
therefore, a baseline was introduced to exclude pre-existing violations, and manual code review remains necessary.
